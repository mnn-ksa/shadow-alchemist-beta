# Shadow Alchemist — test builds

Android test builds of **Shadow Alchemist**. This repository only holds the builds; the game's source is private.

## التثبيت أول مرة

1. من جوالك افتح الرابط هذا وحمّل اللعبة:
   **https://github.com/mnn-ksa/shadow-alchemist-beta/releases/latest/download/ShadowAlchemist-beta.apk**
2. افتح الملف بعد ما يخلص التحميل. إذا طلب الجوال إذن **«تثبيت التطبيقات غير المعروفة»** للمتصفح أو لتطبيق «ملفاتي»، فعّله وارجع كمّل التثبيت.
3. **جوالات سامسونج:** إذا رفض التثبيت بسبب **«الحظر التلقائي» (Auto Blocker)**، أطفئه مؤقتًا من:
   الإعدادات ← الأمان والخصوصية ← الحظر التلقائي.
4. إذا طلع تنبيه من **Google Play Protect**، اختر «مزيد من التفاصيل» ثم «التثبيت على أي حال».

## التحديثات

اللعبة تشيك على التحديثات كل ما تفتحها، وكل نص ساعة وهي مفتوحة. إذا فيه نسخة جديدة يطلع لك **NEW TEST BUILD**، اضغط **UPDATE**.
أول مرة بس، أندرويد يطلب إذن **«السماح من هذا المصدر»** للعبة. فعّله وارجع للعبة، وبعدها اضغط **تحديث**. تقدّمك يبقى زي ما هو.

## الإبلاغ عن مشكلة

**Menu ← Report a problem** (أو من Settings).

1. اختر نوع المشكلة.
2. اضغط **SEND**.
3. اختر واتساب وأرسلها للي عطاك اللعبة.
4. اكتب في الرسالة وش صار.

التقرير يرسل معه صورة للشاشة وحفظك وسجل اللعبة. وإذا اللعبة قفلت فجأة، بتسألك أول ما تفتحها إذا تبي ترسل تقرير.
